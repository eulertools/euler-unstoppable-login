# euler-unstoppable-login

Next.js app that connected Euler Tools staking to Unstoppable Domains login. Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/euler-unstoppable-login-archive`.

## What was built (EN)

Next.js + iron-session. Unstoppable OAuth client id/secret and session password come from env (`.env.example` leaves them empty). Public env lists the BSC token and staking contracts (on-chain, not secrets).

Hackathon write-up, demo video, and original contact details are kept as historical.

## Qué se construyó (ES)

Login Unstoppable + staking Euler. Secretos OAuth por entorno.
